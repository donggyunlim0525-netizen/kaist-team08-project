# KAIST MBA — Team 8 · 득근음료

프로틴 음료를 단백질 함량 기준 S/A/B/C 티어로 분류·비교해주는 웹 MVP입니다.

팀원: 임동균 (PM 리드), 장래희 (기획 리드), 김강 (개발 리드), 이윤표 (데이터·디자인, 성분·규제 판단)

## 서비스 개요

편의점 앞에서 프로틴 음료의 성분표를 일일이 비교하지 않고, 단백질 함량으로 티어를 나눠 빠르게 고를 수 있게 돕는 서비스입니다.

- **티어 기준** (100ml·g당 단백질): S 40g↑ / A 30g↑ / B 20g↑ / C 10g↑ (당 함량은 기준에서 제외, 10g 미만 제외)
- **데이터**: 식품안전나라 품목제조보고(C002) + 식약처 식품영양성분 DB 조인 → 13,130개 제품
- **티어 대상**: 아미노산류·비음료 제형(정·분말 등) 제외 후 1,335개 (S 314 / A 134 / B 223 / C 664)
- **현재 화면**: 홈 = 검색 + 티어리스트, 티어별 상세 페이지, 제품 상세(영양성분·원재료), 티어 기준은 클릭으로 공개
- **이미지**: 식품유형별 예시 이미지(가상) 사용 중, 추후 실제 제품 사진으로 교체 예정
- **MVP**: 팀 공유용 정적 뷰어 링크 참고 (아래 제출 링크)

## 진행 상태와 남은 작업

1. MVP 티어리스트 구현 완료 (검색 + S/A/B/C 티어 + 상세 페이지).
2. 데이터 파이프라인 완료 (C002 수집·영양성분 조인·전처리·비음료/아미노산류 제외).
3. 경쟁사 분석 완료 (Week 6-2 프레임워크: 4층위 매트릭스·2x2 포지셔닝·ERRC).
4. 남은 작업:
   - 팀원 피드백 반영 (정적 뷰어 링크로 확인 후)
   - 티어·등급 표시의 규제 검토 (성분·규제 담당 확인 후 면책 문구 확정)
   - 실제 제품 사진 교체
   - 인터뷰 기반 포지셔닝 축 검증
