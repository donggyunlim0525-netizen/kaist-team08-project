# WhyTree — 음료 성분 비교 서비스
작성자: 장래희 | 2026-10-29

## 최상위 Why
내 기준에 맞는 음료를 빠르고 확신 있게 선택한다.

## Why → How
- 탐색 시간과 노력을 줄인다
  - 원하는 조건에 맞는 후보를 좁힌다
    - 성분 조건 필터링 [씨앗]
    - 제로/고단백/기능성 카테고리 [씨앗]
  - 적합한 새로운 상품을 발견한다
    - 음료 상품 목록 [씨앗]
    - 신제품 업데이트 [추가 아이디어]
- 성분을 이해하고 비교하여 선택의 확신을 높인다
  - 상품 간 차이를 확인한다
    - 영양성분 비교 [씨앗]
  - 제품 정보를 신뢰한다
    - 데이터 출처 표시 [씨앗]
    - 정보 검증 및 수정 요청 [추가 아이디어]

주요 연결: 성분 필터링 → 후보 축소 → 탐색 시간 절감 → 빠른 선택.
부가 연결: 성분 필터링 → 상품 비교의 용이성 → 선택의 확신.

## 미검증 가정
외부 유저 인터뷰와 식약처 API의 대상 음료 커버리지 검증은 아직 완료되지 않았다.
