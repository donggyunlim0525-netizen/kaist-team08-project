# WhyTree — 청담음료

- 이름: 임동균 (donggyun)
- 날짜: 2026-10-26
- 대상: 매일 음료를 마시는 30~40대 건강 관심 소비자

```
안심하고 고르는 매일의 한 잔
├─ 후회 없이 선택하기
│  ├─ 내 기준에 맞는 음료 발견하기
│  │  ├─ 목표별 탐색
│  │  └─ 조건 필터로 좁히기
│  ├─ 믿고 선택하기
│  │  └─ 제품 상세·성분 해설 (부가적인 why — 점선)
│  ├─ 쉽게 이해하고 비교하기
│  │  ├─ 제품 상세·성분 해설
│  │  ├─ 랭킹·정렬로 비교하기
│  │  └─ 성분 점수로 한눈에 보기 (아직 하지 않는 일 — 점선 상자)
│  └─ 샘플러로 먼저 맛보기 (아직 하지 않는 일 — 점선 상자)
└─ 내게 맞는 음료 놓치지 않기
   └─ 관심 음료 소식 먼저 받기
      └─ 출시 알림 신청
```

- 실선 = 가장 중요한 why / 점선 = 부가적인 why / 점선 상자 = 아직 하지 않는 일
- 제품 상세·성분 해설의 가장 중요한 why는 "쉽게 이해하고 비교하기"라 실선, "믿고 선택하기"에도 도움이 돼 점선으로 이었다.
