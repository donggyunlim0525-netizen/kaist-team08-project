# WhyTree — 득근음료

- 이름: 김강 (kim-kang)
- 날짜: 2026-10-29
- 대상: 운동하며 단백질 음료를 정기적으로 사 마시는 30~40대 웰니스·피트니스인

```
운동한 만큼 몸이 바뀌는 매일
├─ 내 운동 목표에 맞게 먹기
│  ├─ 목표에 맞는 음료 고르기
│  │  ├─ 목표별 추천 순위 보기          ← 이번 스펙
│  │  └─ 조건 필터로 좁히기
│  └─ 성분을 한눈에 이해하기
│     └─ 단백질·당류·칼로리 비교
├─ 돈 아끼며 꾸준히 먹기
│  ├─ 단백질 1g당 가격 비교
│  └─ 정기구매 최저가 알림 (아직 하지 않는 일)
└─ 새 음료 놓치지 않기
   └─ 인디 브랜드 신제품 소식 받기 (아직 하지 않는 일)
```

- How Down: "돈 아끼며 꾸준히 먹기"의 다른 방법으로 1g당 가격 비교를 찾았다.
