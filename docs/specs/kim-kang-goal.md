# 사양서 — 목표별 추천 순위 보기

- 작성: 김강 (kim-kang) · 2026-10-29
- WhyTree 노드: 목표별 추천 순위 보기 → 목표에 맞는 음료 고르기 → 내 운동 목표에 맞게 먹기

## 1. 누구를 위해, 언제 문제가 생기나
- 대상: 운동하며 단백질 음료를 정기적으로 사는 30~40대.
- 순간: 다음 달 정기구매 전, "벌크업 중인데 어떤 걸 사야 하지?"라고 고민할 때.
- 문제: 제품마다 단백질·당류·칼로리가 달라, 내 목표에 맞는 순서로 비교하기 어렵다.

## 2. 사용자 행동 흐름
1. 목표 3개 중 하나를 누른다: 벌크업 / 다이어트 / 운동 후 회복.
2. 목표에 맞는 기준으로 음료가 순위대로 정렬된다.
   - 벌크업: 단백질 많은 순
   - 다이어트: 칼로리 대비 단백질 많은 순 (당류 5g 초과 제외)
   - 운동 후 회복: 단백질 1g당 가격 낮은 순
3. 카드마다 단백질·당류·칼로리·1g당 가격과 "왜 이 순위인지" 한 줄이 보인다.

## 3. 우선순위
- P0: 샘플 음료 10개 내장, 목표 3개 버튼, 목표별 정렬, 카드의 근거 한 줄
- P1: 목표 선택 기억(새로고침 후 유지), 가격 직접 수정
- P2: 식약처 식품영양성분 DB 연동, 개인 체중 기반 추천

## 4. 범위 밖
- 구매·결제, 로그인, 실제 판매가 수집

## 5. AI 모델
- P0에는 AI를 쓰지 않는다. 정렬은 규칙 기반이다.
- (P2) AI 추천을 붙일 경우, 실패하면 규칙 기반 순위를 그대로 보여준다.

## 6. 손으로 하는 확인
1. "벌크업"을 누르면 1위가 샘플 중 단백질이 가장 많은 제품인가?
2. "다이어트"를 누르면 당류 5g 초과 제품이 목록에 없는가?
3. "운동 후 회복"을 누르면 1g당 가격이 오름차순인가?

## 7. 데이터
- 샘플 데이터는 구조 확인용 예시 값이며 실제 제품 성분이 아니다.
